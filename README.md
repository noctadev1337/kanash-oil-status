# KANASH-OIL-STATUS

Небольшое приложение на PyQt6: собирает наличие топлива на АЗС Канаша из трёх источников (2ГИС, Т-Банк, Сбер АЗС), показывает таблицу, рисует статус на карте и сохраняет отчёт в CSV или XLSX.

## Запуск

Нужен Python 3.12+.

```bash
pip install -r requirements.txt
python kanash-oil-status.py
```

В `requirements.txt`: `PyQt6`, `httpx`, `openpyxl`. Для HTTP/2 можно поставить `httpx[http2]`, но он необязателен.

## Как пользоваться

1. Выбери источник (2GIS, T-BANK или SBER) и нажми «Старт». Ход работы идёт в журнале, «Стоп» останавливает парсинг.
2. После завершения появится кнопка «Открыть таблицу»: колонки «Название», «Адрес» и выбранные виды топлива.
3. «Экспорт» в окне таблицы (или «Сохранить отчёт» в меню) пишет файл `дата_источник_oil_status.csv` или `.xlsx` в папку результатов.
4. В «Настройках» выбираются виды топлива (от 1 до 5, по умолчанию 4), папка результатов, формат файла и тема. Папка по умолчанию `results` лежит рядом со скриптом.

Статусы в таблице: «Есть», «Нет», «Возможно», «Н/Д» (нет данных).

## Карта (map painter)

После каждого парсинга (и при открытии архива) автоматически перерисовывается файл `src/map/map_out.png` из `src/map/map_clean.png`:

- `src/map/map_painter.py` — рисует круглые маркеры на 9 фиксированных точках карты (башнефть, газпромнефть, татнефть №65, лукойл, quickstop, танеко/тат-эконом, татнефть янтиковское, татнефть №66, татнефть №68).
- Станции из выбранного источника сопоставляются с точками карты по названию и адресу. Цвет кружка считается по **выбранным в настройках видам топлива** (те же, что в плашке), берётся лучший статус: `yes > maybe > no > unknown`:
  - зелёный — топливо в наличии (`yes`)
  - оранжевый — возможно есть (`maybe`)
  - красный — нет топлива (`no`)
  - серый — нет данных (`unknown`)
- Если станции на точке карты нет в текущем источнике — маркер серый («Нет данных»).
- Станции, которых нет на карте (АГЗС, АГНКС, Новитэк и т.д.), не рисуются, но остаются в таблице и в БД.
- Точка `(631, 134)` подписана как `quickstop (бывш. bestoil)` — окраска под Quick Stop.

## База данных (`src/data/oil_status.db`)

SQLite, три таблицы:

| Таблица | Назначение |
|---------|------------|
| `runs` | История запусков парсинга |
| `run_stations` | Станции одного запуска |
| `fuel_statuses` | Наличие топлива по станциям |

### Схема

```sql
CREATE TABLE IF NOT EXISTS runs (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    source TEXT NOT NULL,          -- '2gis', 'tbank', 'sber'
    created_at TEXT NOT NULL,      -- ISO дата запуска
    stations_count INTEGER NOT NULL -- количество станций в запуске
);

CREATE TABLE IF NOT EXISTS run_stations (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    run_id INTEGER NOT NULL REFERENCES runs(id) ON DELETE CASCADE,
    ext_id TEXT NOT NULL,          -- внешний ID станции из источника
    name TEXT NOT NULL,            -- название АЗС
    address TEXT NOT NULL,         -- адрес
    UNIQUE(run_id, ext_id)
);

CREATE TABLE IF NOT EXISTS fuel_statuses (
    run_station_id INTEGER NOT NULL REFERENCES run_stations(id) ON DELETE CASCADE,
    fuel TEXT NOT NULL,            -- 'АИ-92', 'АИ-95', 'ДТ', 'Газ', 'АИ-98'
    status TEXT NOT NULL CHECK(status IN ('yes', 'no', 'maybe', 'unknown')),
    PRIMARY KEY (run_station_id, fuel)
);
```

### Методы БД (`src/db.py`)

| Метод | Описание |
|-------|----------|
| `ensure()` | Создаёт таблицы, если их ещё нет |
| `connect()` | Подключение к `src/data/oil_status.db` |
| `save_run(source, rows)` | Сохраняет запуск: создаёт запись в `runs`, станции в `run_stations`, статусы топлива в `fuel_statuses` |
| `list_runs()` | Возвращает список всех запусков (для архива) |
| `load_rows(run_id)` | Загружает станции и топлива данного запуска |
| `delete_run(run_id)` | Удаляет запуск и связанные станции/статусы |

Вызовы: `save_run(source_code, rows)` — после парсинга; `load_rows(run_id)` — при открытии архива.

## Важно

- С включённым VPN запросы могут не проходить.
- Для Т-Банка проверка SSL-сертификата отключена (сертификат отозван), остальные источники проверяются как обычно.
- Все три API неофициальные, формат ответа может измениться.
- Названия одних и тех же АЗС отличаются в разных источниках (QuickStop / Квикстоп, Тат-эконом / Эконом и т.д.), сопоставление на карте и в отчётах сделано по названию + адресу.
